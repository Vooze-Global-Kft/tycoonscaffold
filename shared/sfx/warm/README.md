# Sound pack "warm"

Pizza Empire's pack (the default, `"soundPack": "warm"`): C major pentatonic, marimba, kalimba,
small bells, plate clinks and the service bell. Made with
`python3 scripts/audio/make_sfx.py --pack warm --out shared/sfx/warm`. Only games that name this
pack get these files; a game's own `assets/sfx/` overrides any of them by name.
