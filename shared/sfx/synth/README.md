# Sound pack "synth"

Space Miner's pack (`"soundPack": "synth"` in its game.json). Empty for now: its sounds are made
later with `python3 scripts/audio/make_sfx.py --pack synth --out shared/sfx/synth`. Until then
every event of that game is silent (vibrations still play). Only sound files whose names are
catalogue keys are bundled; this README is not.
